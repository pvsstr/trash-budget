**Осталось только на стороне пользователя (не код):**

1. **Firestore rules (важно!).** console.firebase.google.com → проект trash-budget-737fd → Firestore Database → вкладка Rules → заменить всё на:
```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
    match /{document=**} {
      allow read, write: if false;
    }
  }
}
```
Нажать «Опубликовать». Это закрывает доступ чужих людей к вашим данным даже при наличии projectId.
