# МАЯК — финансовый навигатор

> **Подсвечивает рифы. Ведёт к цели.**

МАЯК — это мобильное веб-приложение (PWA) про личные деньги. Это не калькулятор расходов, а **агент**, который живёт вместе с вашим бюджетом: строит прогноз баланса на 90 дней вперёд, предупреждает о яме заранее, находит утечки, сам распознаёт ваши платежи и учит финансовой грамотности.

**Живая версия:** [pvsstr.github.io/trash-budget](https://pvsstr.github.io/trash-budget/)

---

## Чем МАЯК отличается

| Обычно приложения-тратилки | МАЯК |
|---|---|
| Показывают, что вы потратили | Показывают, **что будет дальше** |
| Молчат до катастрофы | Предупреждают за дни: «к пятнице денег не хватит» |
| Категории вручную | Сам определяет: пишете «Пятёрочка» → Продукты, «Т-банк» → платёж по кредиту |
| Просто цифры | Объясняет каждую цифру словами и советует, что делать |

Всё считается **только по вашим данным**. Никакой рекламы, никакой аналитики, никаких серверов-посредников — данные лежат в вашем личном Firebase-аккаунте.

## Быстрый старт — 5 минут

1. Откройте [приложение](https://pvsstr.github.io/trash-budget/).
2. **Создайте аккаунт**: вкладка «Регистрация» → e-mail и пароль (от 6 символов) → «Создать аккаунт». Либо войдите одной кнопкой через Google.
3. На Панели появится **чек-лист настройки**. Пройдите его по порядку:
   - **Доход и день зарплаты** — две цифры;
   - **Текущий баланс** — сколько на всех картах сейчас;
   - **Обязательные платежи** — аренда, связь, кредиты;
   - **Первый конверт** — например «Продукты» с лимитом.
4. Готово. Дальше приложение работает само: лимит на день, прогноз, предупреждения.

> **Приватность.** Каждый аккаунт — отдельное закрытое хранилище. Ваши данные видны только вам и никому больше. Пароль можно восстановить через «Забыли пароль?», аккаунт удаляется целиком в Настройках.

## Разделы

### Панель

Главный экран. Сверху вниз:

- **Брифинг на сегодня** — сколько осталось тратить сегодня, главный риск дня, ближайшее крупное списание;
- **Предупреждения заранее** — карточки появляются сами, если к дню крупного платежа запас будет меньше 10 дней жизни или баланс уйдёт в минус;
- **Цикл зарплаты** — прогресс цикла, осталось дней, ритм трат (норма / выше темпа / экономия);
- **Платежи на 3 дня** — список с галочками «оплачено» прямо из списка;
- **Календарь** — зарплата, платежи, рассрочки и личные планы;
- **Статистика** — доход, обязательства, утечки, цели, долги, норма сбережений;
- **Аналитика** — любой период: круговая диаграмма, динамика по дням, тепловая карта, привычки в цифрах (средний чек, дорогой день недели, выходные против будней);
- **«Что важно сейчас»** — умные сигналы с приоритетами: от «денег не хватит через N дней» до «подписка подорожала».

### Траты

- Полная история с поиском, фильтром по категории и любым периодом;
- Режим периода: **календарь или цикл зарплаты**;
- Группировка: по дням, категориям, продавцам;
- Инструменты: вставить выписку банка, найти дубликаты, найти **регулярные платежи**, разобрать «Прочее», сравнить два цикла, экспорт в CSV;
- Частые траты — шаблоны в один тап.

#### Добавить трату

Нажмите «Трата». Форма заточена под скорость:

1. Сумма — клавиатура открывается сама;
2. Название — необязательно. Начните писать «пятё…» — категория подставится сама. Напишите **«Т-банк»** — приложение спросит: *«Это платёж по кредиту?»* — и при подтверждении уменьшит долг и запишет платёж правильно, без двойного учёта;
3. Категория — чипы в один тап. Система предложила неверно? Просто тапните нужную — ваш выбор всегда главнее;
4. Метка: обычная / план / импульс / нужно;
5. Галочка **«перевод себе»** — для перекидывания денег между своими счетами: попадает в историю, но не трогает баланс и статистику;
6. «Сохранить и ещё» — для серии покупок.

Если чек подозрительно крупный (в 3 раза выше вашего обычного) или пробивает дневной лимит — приложение мягко предупредит сразу после сохранения.

Удалили лишнего? После удаления 6 секунд висит кнопка **«Отменить»**.

### Доходы

Поступления с типами (зарплата, подработка, кэшбэк, перевод), структура доходов, сравнение со средним за 6 месяцев. Зарплата добавляется автоматически в день прихода — по фактической дате, с учётом выходных.

### Бюджет

Сердце приложения:

- **Конверты** — любые: своё название, несколько категорий, значок и цвет на выбор. Конверт показывает лимит, траты цикла и темп («вписываешься» / «перебор N ₽»). Из шторки конверта можно сразу добавить трату — там же шаблоны ваших частых покупок;
- **Платежи** — аренда, связь и прочее. Отметка «оплачено» записывает трату автоматически;
- **Подписки** — сумма в месяц и год, аудит по факту: если списание выросло в цене или подписка молчит 90 дней — увидите сигнал;
- **Кредиты** — укажите платёж и день списания один раз, и прогноз, дневной лимит и план долгов станут честными. Карточка показывает «закроете за ~N мес».

### Прогноз

Карточка «Прогноз баланса»: график на 90 дней вперёд — зарплаты, все платежи, подписки, кредиты и ваш личный темп трат с поведенческими коэффициентами (после зарплаты люди тратят больше — приложение это знает).

- Тапните по любому дню — увидите, как сложилась цифра и что делать;
- Щипок и перетаскивание — зум и прокрутка;
- Красная зона = уход в минус, точка «дно» = самая низкая точка;
- **«Что если…»** — симулятор: «урежу кафе на 30%» → новый минимум баланса;
- **«Могу купить?»** — честный вердикт по любой покупке + **список желаний**: записали желание → 24 часа выдержки → время вышло, решайте холодной головой.

### Обучение

18 коротких уроков в двух блоках — «Основы» и «Мастерская МАЯК». Каждый урок — одна минута и одно конкретное действие в приложении.

### Копилот

Чат, который отвечает только по вашим цифрам: «сколько можно сегодня?», «могу купить X?», «где утечки?», «как закрыть долги?», «что будет, если урежу кафе на 30%?», «научи меня», «с чего начать?».

### Настройки

Резервная копия данных одним файлом (+ напоминание, если копии нет 60 дней), переключение цикла (зарплатный/календарный), версия и статус деплоя, полный сброс.

| Раз в месяц | Открыли отчёт за цикл → «Поделиться»; скачали копию данных | 1 минута |

## Как это работает внутри

- **Цикл считается от фактической даты зарплаты**: если 20-е выпало на воскресенье, зарплата придёт 21-го — и цикл начнётся 21-го, а не 20-го. Все периоды, лимиты и отчёты строятся по этой цепочке;
- **Прогноз** учитывает: реальный остаток, ваш средний темп гибких трат × поведенческие коэффициенты фазы цикла, платежи, подписки, кредиты, рассрочки, зарплаты;
- **Сигналы** ранжируются по приоритету: тяжесть × срочность × выгода в рублях;
- **«Минимум на жизнь»** считается автоматически из базовых трат за последние 3 цикла (можно переопределить вручную);
- **Лог решений**: отключили подписку, пополнили цель, отложили платёж — через месяц покажет, сработало ли.

## Данные и приватность

- Все данные — только ваши: хранятся в Firestore под вашим Google-аккаунтом (`users/{uid}`);
- В коде нет ни одной вашей цифры;
- Работает оффлайн (service worker), синхронизируется при появлении сети;
- Экспорт/импорт — обычный JSON-файл, ваш полностью;
- Рекомендуем раз в месяц скачивать копию (Настройки → «Скачать копию данных») — приложение само напомнит через 60 дней.

### Владельцу репозитория: включите правила безопасности

В [консоли Firebase](https://console.firebase.google.com) → проект → **Firestore Database** → **Rules** → замените всё на:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
    match /{document=**} {
      allow read, write: if false;
    }
  }
}
```

И нажмите «Опубликовать». Без этого любой знающий projectId может читать чужие коллекции.

**Ещё один переключатель для владельца:** Firebase Console → **Authentication** → **Sign-in method** → включите провайдеры **Email/Password** и **Google** — без них соответствующие кнопки входа не заработают.

## Если что-то не так (FAQ)

<details>
<summary><b>Не заходит через Google / крутится «Подключаюсь…»</b></summary>

Разрешите всплывающие окна для этого сайта. Если не помогло — приложение само переключится на резервный вход через редирект. Проверьте, что домен `pvsstr.github.io` добавлен в Firebase Console → Authentication → Settings → Authorized domains.
</details>

<details>
<summary><b>Забыл пароль</b></summary>

Экран входа → «Забыли пароль?» → введите e-mail → письмо со ссылкой придёт в течение минуты (проверьте «Спам»).
</details>

<details>
<summary><b>Хочу удалить аккаунт и все данные</b></summary>

Настройки → «Аккаунт» → «Удалить аккаунт и данные». Сначала скачайте копию данных там же. Для защиты аккаунт требует недавнего входа: если удаление не прошло — выйдите, войдите заново и повторите.
</details>

<details>
<summary><b>Регистрировался по e-mail, а вошёл через Google — данные «пропали»</b></summary>

Для приложения это два разных аккаунта с разными хранилищами. Всегда используйте один и тот же способ входа. Если создали второй случайно — войдите первым способом, а новый удалите в Настройках.
</details>


<details>
<summary><b>Открыл с другого устройства — данные пустые</b></summary>

Вы вошли под другим Google-аккаунтом. Выйдите (кнопка внизу слева) и войдите тем же аккаунтом, что раньше. Данные привязаны к аккаунту, а не к устройству.
</details>

<details>
<summary><b>Удалил(а) трату/операцию случайно</b></summary>

После удаления 6 секунд доступна кнопка «Отменить» во всплывающем уведомлении. Если окно уже исчезло — операцию можно создать заново вручную.
</details>

<details>
<summary><b>Приложение показывает старое после обновления</b></summary>

Дёрните страницу «потянуть-обновить» или закройте и снова откройте вкладку. Статус деплоя виден в Настройках внизу — когда там зелёная точка, версия точно свежая.
</details>

<details>
<summary><b>Иконка на телефоне старая / называется по-другому</b></summary>

Удалите установленное приложение-ярлык и установите заново: открыть сайт → меню браузера → «Добавить на главный экран». Имя и значок берутся из манифеста в момент установки.
</details>

<details>
<summary><b>Цикл отображается «не с 20-го»?</b></summary>

Так и задумано: цикл начинается с <b>фактической</b> даты прихода зарплаты. 20-е на воскресенье → зарплата 21-го → цикл 21.09–19.10. Хотите строгие календарные месяцы — Настройки → «Основной цикл» → Календарный.
</details>

<details>
<summary><b>Как изменить доход или день зарплаты?</b></summary>

Панель → карточка «Доход в месяц» → поменяйте числа → Сохранить.
</details>

<details>
<summary><b>Как исправить баланс, если расхождение с банком?</b></summary>

Панель → «Реальный остаток» → «Обновить базовый баланс» → введите сумму с карты. Всё пересчитается мгновенно.
</details>

<details>
<summary><b>Прогноз пугает минусом — он точен?</b></summary>

Точен настолько, насколько полны данные. Три вещи, которые делают его честным: актуальный баланс (сверяйте раз в пару недель — приложение напомнит), платежи по кредитам заполнены (Бюджет → Кредиты → платёж и день), история трат хотя бы за цикл. Симулятор «Что если…» покажет, как изменить картину.
</details>

<details>
<summary><b>Восстановление из копии</b></summary>

Настройки → «Восстановить из файла» → выбрать JSON, скачанный ранее. Осторожно: текущие данные будут заменены.
</details>

<details>
<summary><b>Оффлайн работает?</b></summary>

Да. Просмотр, добавление трат — да. Первый вход и синхронизация требуют сети.
</details>

## Для разработчика

**Стек:** чистые HTML + CSS + Vanilla JS (ES5, без сборщиков и зависимостей) + Firebase (Auth + Firestore). Деплой автоматический: push в `main` → GitHub Actions → Pages.

```
├── index.html        каркас: логин, навигация, шторки
├── app.js            вся логика (~6600 строк)
├── style.css         тёмная тема, glass-стиль, адаптив
├── icons.js          SVG-спрайт иконок
├── favicon.svg       значок вкладки / PWA
├── manifest.json     PWA-манифест
├── sw.js             service worker (network-first + офлайн-кэш)
└── pages/*.html      7 страниц: dash, spend, income, budget, learn, chat, settings
```

**Правила кода:** ES5 строго (`var`, без стрелок и шаблонных строк), никаких эмодзи в интерфейсе, весь текст интерфейса — русский, данные пользователя — только в Firebase (в коде цифр нет). Перед пушем: `node --check` копии `app.js`.

**История проекта и точки отката** — в [SESSION.md](SESSION.md): карта кода, журнал изменений, backup-теги `backup/*`.
