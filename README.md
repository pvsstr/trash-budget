## О проекте

**МАЯК** — это не калькулятор расходов, а **финансовый агент**, который живёт вместе с вашим бюджетом. Приложение строит прогноз баланса на 90 дней вперёд, предупреждает о financial pitfalls заранее, находит утечки денег, автоматически распознаёт категории трат и учит финансовой грамотности.

Всё считается **только по вашим данным**. Никакой рекламы, никакой аналитики сторонних серверов — данные хранятся в вашем личном Firebase-аккаунте.

**Живая версия:** [pvsstr.github.io/trash-budget](https://pvsstr.github.io/trash-budget/)

## Ключевые возможности

| Возможность | Описание |
|---|---|
| **Прогноз на 90 дней** | График баланса с учётом платежей, подписок, кредитов и поведенческих коэффициентов |
| **Автокатегоризация** | Пишете «Пятёрочка» → Продукты, «Т-банк» → платёж по кредиту |
| **Метод конвертов** | Лимиты по категориям с визуальным контролем перерасхода |
| **План выхода из долгов** | Avalanche vs Snowball стратегии с расчётом сроков и процентов |
| **«Могу купить?»** | Честный вердикт по любой покупке с прогнозом на 90 дней |
| **«Что если?»** | Симулятор: «урежу кафе на 30%» → новый минимум баланса |
| **Аудит подписок** | Сравнение заявленной цены с реальными списаниями |
| **Умные сигналы** | 15+ типов предупреждений с приоритизацией |
| **Обучение** | 18 коротких уроков по финансовой грамотности |
| **Копилот** | Чат, отвечающий по вашим финансовым данным |
| **Бэкап данных** | Экспорт/импорт JSON-файла с валидацией целостности |
| **Оффлайн-работа** | Service Worker кэширует для работы без интернета |

## Быстрый старт

### Онлайн (рекомендуется)

1. Откройте [приложение](https://pvsstr.github.io/trash-budget/)
2. Создайте аккаунт: e-mail + пароль (от 6 символов) или войдите через Google
3. Пройдите чек-лист настройки на Панели:
   - Доход и день зарплаты
   - Текущий баланс
   - Обязательные платежи
   - Первый конверт

### Локальная разработка

```bash
git clone https://github.com/pvsstr/trash-budget.git
cd trash-budget
# Откройте index.html в браузере
# Или запустите локальный сервер:
python -m http.server 8000
# Откройте http://localhost:8000
```

## Правила безопасности Firebase

См. `firestore.rules` в корне репозитория. Правила обеспечивают:
- Каждый пользователь видит **только свои данные**
- Запись разрешена только авторизованным пользователям к своему документу
- Все остальные пути закрыты
